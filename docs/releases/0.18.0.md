# Yggdrasil 0.18.0 — Local Workspace

Prepared on 2026-11-16. This document is a release draft; it does not indicate
that packages, tags or a GitHub release have been published.

## A local interface, with its own experimental version

Run `ygg` to open the local Workspace. The product version is **Yggdrasil 0.18.0**;
the interface is independently versioned **UI 0.1 Experimental** (package version
`0.1.0`). Existing CLI commands are preserved, including `ygg --help`,
`ygg -help` and `ygg help`.

Projects bring together an overview, searchable knowledge and sources.
Settings contains the full CLI configuration and model selection for background
processing and embeddings. English is the default language; Russian, German,
Spanish, French, Japanese and Chinese are also available. Five palettes each
support light and dark modes.

## Operations for everyday tasks

Seed existing history, check the installation and sync memory from three task
cards. The command selector groups 14 everyday commands with descriptions;
advanced commands appear when requested. Seed starts with `--dry-run` so the
first run previews the import. Progress, logs, interactive input, stop controls
and confirmations remain part of the operation flow.

Aliases, server/stdio commands, token commands and UI launch commands are omitted
from the selector; they remain available in the CLI. Configuration has its own
Settings flow, and updates are reached through the version badge.

## Updates and release metadata

The sidebar shows the installed product version and cached GitHub star metadata.
When an update is available, the version badge opens a confirmation and log view
for `ygg update`. The operation can continue with the dialog closed; an indicator
shows that it is running. After verifying the installed version, Workspace
restarts with the browser session preserved and shows a Sonner notification.

## Experimental scope

Graph and Chat are temporarily hidden from navigation, project pages and related
actions. Existing chats, relation data and backend modules are preserved.
This release does not delete them or migrate them into another store.

See the [Workspace guide](../workspace.md) for launch, configuration, operation
and update details. The README images use isolated, fictional English data:
[projects](../screenshots/workspace-projects.png),
[project overview](../screenshots/workspace-project.png) and
[operations](../screenshots/workspace-operations.png).
The [expanded command menu](../screenshots/workspace-command-menu.png) shows
the grouped selector and per-command descriptions. To reproduce these images,
build the web app and run `python3 scripts/workspace_screenshot_demo.py` from
the repository root; see the [development guide](../../web/README.md).

## Publication handoff

The product version is aligned in the Python package, npm wrapper, MCP bundle
and registry metadata, and Claude, Codex and Cursor plugin manifests. The web
package keeps its independent UI version `0.1.0`.

Publication is a separate authorized action. No commit, tag, push, package
publication, installed-user update or real-user data migration is part of this
preparation. The Homebrew formula remains unchanged: its archive URL and SHA-256
must be taken from the actual published 0.18.0 source artifact during publication,
not guessed or substituted with a local build hash. `scripts/release.sh` was not
run as part of preparing these notes.
