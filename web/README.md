# Yggdrasil Workspace — UI 0.1 Experimental

React + TypeScript, Tailwind CSS, компоненты shadcn/ui на Radix, Three.js.
Версия интерфейса — **0.1.0**, статус — **Experimental**; версия пакета
Yggdrasil — **0.18.0**. Интерфейс работает с настоящим API локального Workspace.
Фикстуры со скриншотами используют отдельные вымышленные данные и не подменяют
API в обычном приложении.

Доступны проекты (обзор, знания, источники), Operations и Settings. Graph и
Chat временно скрыты: страницы, навигация и действия открытия чата недоступны,
а серверные модули и сохранённые диалоги остаются на месте. Operations показывает
карточки seed/doctor/sync, 14 основных команд с описаниями и группами, а также
отдельно включаемые дополнительные команды. По умолчанию seed использует
`--dry-run`. Полная конфигурация открывается в Settings, обновления — через
значок версии. Команды CLI сохранены.

Семь языков, английский по умолчанию; пять палитр со светлым и тёмным режимами.
Пользовательское руководство: [docs/workspace.md](../docs/workspace.md).

## Сборка

```bash
cd web
npm ci
npm test
npm run build
```

Сборка записывается в `yggdrasil/workspace_static/` и входит в Python-пакет.
Пользователю Node.js не нужен: приложение открывается командой `ygg`.
Шрифты Manrope (кириллица и латиница) и Three.js включены в локальную сборку.
Модули графа сохранены для дальнейшей разработки; в UI 0.1 Experimental граф скрыт.

## Разработка

Запустите Workspace через `ygg ui --no-open`, затем `npm run dev` в этой папке.
Vite слушает только `127.0.0.1:5173`, проксирует `/api` на `127.0.0.1:42070`.
Откройте напечатанный CLI адрес, заменив порт на `5173` и сохранив одноразовый
fragment `#ticket=…`. Билет действует недолго: при истечении повторите команду.
При нестандартном порте Workspace измените target и Origin в vite.config.ts.
Прокси меняет Origin только для собственного `http://127.0.0.1:5173`.

## Проверки

DOM-тесты проверяют границы API и сессии, фильтрацию проектов, принадлежность
диалога, разбор потоковых сообщений и игнорирование поздних ответов после
смены диалога. `npm run build` включает строгую проверку TypeScript.
Браузерная проверка и реальная генерация модели выполняются отдельно;
прохождение DOM-тестов не означает, что они выполнены.

## Скриншоты для README

После сборки из корня репозитория запустите:

```bash
python3 scripts/workspace_screenshot_demo.py
```

Откройте напечатанный одноразовый URL. Скрипт создаёт временный `YGG_HOME`
и базу с шестью вымышленными англоязычными проектами. Пользовательские данные
не читаются, обращения к внешним сервисам и запуск команд отключены.
История операций — демонстрационные записи, а не настоящие запуски.
Число звёзд GitHub в демо зафиксировано на 22; версия берётся из пакета
(для текущих скриншотов — 0.18.0).
Главная страница, `/project?project=Atlas%20Commerce&tab=overview` и
`/operations` используются для изображений в `docs/screenshots/`.
Для пересъёмки выберите английский язык и светлую зелёную палитру.
Остановите демонстрационный сервер через Ctrl+C: временная база будет удалена.
